# Project validation rule

For work in this repository, do not create permanent unit, regression, integration, end-to-end, or smoke tests. Do not make automated test runs a completion gate. Validate changes manually in the running app and, when relevant, in local or hosted Supabase with separate player identities. Record the scenario, expected behavior, observed result, and any unresolved issue in the work summary or the relevant handoff document.

Existing test files may remain as historical project material. Do not extend or run them for new work unless the user changes this rule.
